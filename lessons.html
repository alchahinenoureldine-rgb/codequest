Lessons

HTML: Your first page

HTML describes the structure of a page using tags.

<h1>Hello</h1>
<p>This is a paragraph.</p>
<a href="https://rhu.edu.lb">A link</a>
HTML: Lists and images

Use ul and li for lists, and img to show a picture.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
<img src="photo.jpg" alt="My photo">
CSS: Colors and fonts

CSS controls how elements look.

h1 { color: teal; font-size: 2rem; }
p { background: #eee; padding: 10px; }
CSS: Flexbox layout

Flexbox arranges items in a row or column.

.box { display: flex; gap: 1rem; justify-content: center; }
JavaScript: Variables and functions

Variables store data and functions run reusable code.

const name = "Noureddine";
function hello() { return "Hi " + name; }
console.log(hello());
JavaScript: Events

JavaScript makes pages interactive by reacting to user actions.

document.getElementById("b").onclick = () => alert("Hi!");
