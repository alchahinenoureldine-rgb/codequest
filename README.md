# ⚔️ CodeQuest

A gamified web development learning platform where beginners learn HTML, CSS and JavaScript through levels, live coding, quizzes, XP points and badges.

**🔗 Live demo:** https://alchahinenoureldine-rgb.github.io/codequest/

## Features
- 🗺️ Learning roadmap with levels that unlock as you progress
- 📚 Lessons with code examples
- 💻 Live code playground (HTML, CSS, JavaScript) with instant preview
- 🧠 Timed quizzes with scoring and instant feedback
- 🏆 XP, levels and badges
- 📊 Progress dashboard with a chart and quiz history
- 🌓 Dark and light mode
- 📱 Responsive design for phones and laptops
- ✉️ Contact form with JavaScript validation

## Pages
1. Home
2. Roadmap
3. Lessons
4. Playground
5. Quiz
6. Progress
7. About & Contact

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- localStorage (to save progress in the browser)
- Git and GitHub
- GitHub Pages (hosting)

## How to run locally
1. Clone the repository:
   `git clone https://github.com/alchahinenoureldine-rgb/codequest.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
